# Example ion fragments

`cations.csv` and `anions.csv` provide a small starter library for the optional
ion-pair design example in `il_property_prediction/scripts/run_design_agent.py`.
Each row records a name, charged SMILES, ion family, formal charge, and note.

These examples are separate from the experimental benchmark and from the
training-domain ion library used for the manuscript screening study. The
manuscript candidate space and final shortlist are recorded in
`experiments/manuscript_figure_source_data/computational_application_case/`.
