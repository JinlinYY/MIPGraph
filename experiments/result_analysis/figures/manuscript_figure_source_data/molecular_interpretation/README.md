# Molecular structure–property source data

The panel tables under `source_data/` provide the numerical evidence for the
main-text structure–property association figure and the SI molecular-size control analysis.

- Panel a: integrated structural associations and cross-ion attention contrasts.
- Panel b: condition-adjusted leading structure–property associations.
- Panel c: IL-identity-level response shapes with bootstrap intervals.
- Panel d: condition-matched cation/anion substitution differences.
- SI: heat-capacity association after controlling molecular size.

`column_dictionary.csv` defines the chemical and statistical fields. Property
coverage and uncertainty labels are retained alongside the corresponding
estimates. Final figures are under `experiments/result_analysis/figures/`.

The analysis and export entry points are described in
[`../../../../molecular_interpretation/README.md`](../../../../molecular_interpretation/README.md).
